## 写作口径

- **语言**：简体中文；代码标识符、命令、文件名用英文并加反引号。首次出现的英文术语可在括号中注明中文。
- **语气**：陈述事实，说明「做什么、怎么做」，不使用「完全自主可控」「全链路闭环」等宣传用语，不用感叹号。
- **硬件**：写通用要求（如「NVIDIA GPU，建议显存 ≥ 8 GB」），具体型号只作为示例出现。
- **隐私**：文档、示例与测试不出现真实姓名、学号、班级、个人扫描件内容或个人机器参数；示例书写者用「张三」等通用名。
- **命令**：每条命令单独一个 `bash` 代码块，可直接复制运行。
- **链接**：文档之间用相对路径互相引用；接口以 `docs/openapi.json` 为准。
