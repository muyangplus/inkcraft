# 写字机连接与控制

墨迹工坊通过 USB 串口驱动 GRBL 1.1 写字机（兼容 GRBL 0.9）。机器的全部参数保存在 **机台档案** 中，
可在工作台「GRBL 连接与档案 → 配置」编辑。

## 1. 首次连接

1. 安装 USB 串口驱动（多数写字机为 CH340，也常见 CP210x），插上写字机。
2. 在「GRBL 连接与档案」选择机台档案，串口保持 **自动识别**（COM 号随 USB 口变化，无需手动选择），点击连接。
3. 打开「配置 → GRBL 固件参数」点击读取，确认步数（`$100–$102`）、速度与加速度符合机器。
4. **确认方向**：在点动面板按 **↓**，笔应朝纸张下方移动；若相反，修改「机器 +Y 方向」。
   步进 Z 笔控再按 **Z↓** 确认笔尖朝纸面移动，然后用「抬笔 / 落笔测试」微调落笔高度。
5. 把笔尖移到纸张左上角并「置零」（或开启「开始时自动置零」），执行「外框试跑」确认范围后开始书写。

## 2. 内置机台档案

| 档案 | 笔控 | 说明 |
| --- | --- | --- |
| `kx_grbl_stepper_z` 奎享兼容 · 步进Z | 步进 Z（Z0 抬 / Z2 落，Z 速度 3000） | 左上原点、向下书写为 -Y；落笔后与抬笔前各停 0.2 s；书写 1500、点动 2500 mm/min；开始时自动置零 |
| `kx_grbl_laser` 奎享兼容 · 激光 | `M3 S1000` / `M5` | 其余同上 |
| `corexy_servo_a4` CoreXY A4 舵机 | `M5` 抬 / `M3 S90` 落 | 坐标恒为正的传统 CoreXY 写字机 |
| `gantry_z_a3` 龙门 A3 步进Z | `G0 Z5` 抬 / `G1 Z0` 落 | 坐标恒为正的龙门写字机 |

以上均为通用出厂值，请按自己的机器调整；配置弹窗顶部可一键套用模板。

## 3. 机台档案参数

| 分类 | 参数 | 说明 |
| --- | --- | --- |
| 串口 | `port`、`baud` | `port = auto` 时连接时自动识别 USB 串口 |
| 笔控 | `pen.mode` | `servo` 自定义 M 指令；`z` 步进 Z（`G0 Z抬` / `G1 Z落 F速度`）；`laser` `M3 S功率` / `M5` |
| 笔控 | `z_up_mm`、`z_down_mm`、`z_feed`、`laser_power` | 支持 Z0 抬笔、Z+ 落笔的机器 |
| 时序 | `dwell_ms`、`down_delay_ms`、`up_delay_ms` | 机构稳定时间、落笔后暂停（出墨）、抬笔前暂停 |
| 速度 | `feed_draw`、`feed_travel`、`jog_feed`、`z_jog_step_mm` | 书写、空移、点动速度与 Z 点动步长 |
| 坐标 | `origin`、`x_axis`、`y_axis`、`swap_xy` | 零点所在纸角（四角）、机器 +X / +Y 指向纸面哪一侧、XY 对调 |
| 坐标 | `offset_mm`、`rotation_deg`、`invert_x/y` | 整体偏移、绕纸面中心旋转（纠正纸张放歪）、左右 / 上下镜像 |
| 范围 | `workspace_mm`、`pen_change_pos_mm`、`paper_change_pos_mm` | 工作区（软限位）、换笔位、换纸位（纸面坐标） |
| 流程 | `auto_zero_on_start`、`sleep_after_job` | 开始时 `G92 X0 Y0`；完成后 `$SLP` 休眠 |
| 发送 | `stream_mode` | `char_count` 字符计数流控（默认）；`line` 单步，每行等待 `ok` |
| 扩展 | `start_gcode`、`end_gcode`、`macros` | 自定义起止代码（换行或 `;` 分隔）；最多 8 个宏，点动面板一键执行 |
| 兼容 | `legacy_grbl`、`grbl_expected` | 强制 GRBL 0.9 行为（也会按欢迎语自动识别）；连接时校验的固件参数期望值 |

坐标换算的完整定义见 [FEATURES.md 第 4 节](FEATURES.md#4-坐标约定)。

## 4. 固件参数

「配置 → GRBL 固件参数」读取 `$$` 并显示名称，修改后点击写入（`$N=值`，保存在控制板 EEPROM，对所有上位机软件生效，修改前建议记录原值）。
连接时会自动检查：

- `$13=1`（以英寸上报）：状态坐标自动换算为毫米，暂停续写位置不受影响；
- 舵机笔控时 `$32=1`（激光模式）：提示改为 `$32=0`，否则空移时 PWM 关闭会影响舵机角度；
- 激光笔控时 `$32=0`：提示改为 `$32=1`，避免空移拖出连线；
- `grbl_expected` 中关键参数（`$3`、`$13`、`$100–$102`）与固件不一致：提示确认是否连接了正确的机器。

## 5. 安全操作

- **舵机接线约定**：`M5`（PWM=0）应为抬笔，确保上电、报警或软复位时笔尖自动抬起。
- **外框试跑**：正式书写前，全程抬笔沿本页内容外接矩形走一圈，核对纸张位置与工作区。
- **暂停与换笔**：暂停 → 等待完全静止 → 换笔（移至换笔位）→ 更换笔芯并测试抬落笔 → 续写，从断点原位继续。
- **急停**：立即发送软复位（`0x18`）；步进 Z 笔控收到重启后始终 **朝抬笔方向** 退刀（适用于 Z+ 落笔的机器）。
  排查后需手动解锁（`$X`）才能恢复。
- **激光笔控**：佩戴防护眼镜，并开启 `$32=1`。

## 6. 奎享雕刻兼容

原先用奎享雕刻驱动的 GRBL 写字机可以直接改用墨迹工坊，**无需安装、导入或依赖奎享雕刻的任何文件**。
本方案依据其安装目录 `default.properties` 中公开的配置项说明与 GRBL 1.1 协议独立实现，未使用其程序代码、字体或用户数据。

| 奎享设置 | 墨迹工坊对应项 |
| --- | --- |
| 笔控类型（舵机 / 步进电机 / 激光） | `pen.mode` = `servo` / `z` / `laser` |
| zOn / zOff / zSpeed | `z_down_mm` / `z_up_mm` / `z_feed` |
| laser_power | `pen.laser_power` |
| tool_on_delay / tool_off_delay | `down_delay_ms` / `up_delay_ms` |
| feed_rate / jog_speed | `feed_draw` / `jog_feed` |
| Z 点动步长 | `z_jog_step_mm` |
| 坐标系位置（左上 / 右上 / 左下 / 右下） | `origin`；奎享「左上」机器对应 `y_axis = up`（向下书写为 -Y） |
| 对调 XY / 反转 X / 反转 Y | `swap_xy` / `x_axis` / `y_axis` |
| 横纵坐标偏移、旋转 | `offset_mm`、`rotation_deg` |
| auto_set_zero / autoSleep / single_step_command | `auto_zero_on_start` / `sleep_after_job` / `stream_mode = line` |
| 开始前 / 结束后自定义代码、宏 1–3 | `start_gcode` / `end_gcode`、`macros` |
| 兼容旧版 GRBL | `legacy_grbl` |
| GRBL 参数设置 | 「GRBL 固件参数」面板 |
| 字体 + 概率 | 「书写者 → 多字体混写」 |
| TXT 编码 GBK | 导入时自动识别 |

“奎享雕刻”为其权利人的商标；奎享的 `.gfont` 字体为加密格式，墨迹工坊不读取。
