# 写字机控制方案（兼容奎享雕刻式 GRBL 写字机）

墨迹工坊原生实现了一套 GRBL 写字机控制方案，覆盖奎享雕刻等国产写字机软件常用的控制方式。
原先用奎享雕刻驱动的 GRBL 写字机，可以直接改用墨迹工坊书写，**无需安装、导入或依赖奎享雕刻的任何文件**。

> 本方案依据奎享雕刻公开的配置项说明（安装目录 `default.properties` 中的注释）与 GRBL 1.1 协议独立实现，
> 未使用其程序代码、字体或用户数据。下文「奎享对应项」仅用于帮助熟悉奎享的用户找到同等设置。

## 1. 控制项对照

| 功能 | 墨迹工坊（机台档案） | 奎享对应项 | 说明 |
| --- | --- | --- | --- |
| 串口 | `port = auto` | 端口 | 连接时自动识别 CH340 / CP210x / FTDI 等 USB 串口，COM 号变化无需修改 |
| 笔控方式 | `pen.mode = z / servo / laser` | 笔控类型（步进电机 / 舵机 / 激光） | 步进 Z：`G0 Z抬笔` / `G1 Z落笔 F速度`；激光：`M3 S功率` / `M5`；舵机：自定义 M 指令 |
| 抬笔 / 落笔高度 | `pen.z_up_mm` / `pen.z_down_mm` | zOff / zOn | 支持「Z0 抬笔、Z+ 落笔」的机器；急停时始终朝抬笔方向退刀 |
| Z 轴速度 | `pen.z_feed` | zSpeed | |
| 激光功率 | `pen.laser_power` | laser_power | 建议固件 `$32=1` |
| 落笔后暂停 | `pen.down_delay_ms` | tool_on_delay | 落笔后、开始书写前停顿 |
| 抬笔前暂停 | `pen.up_delay_ms` | tool_off_delay | 一笔写完、抬笔前停顿 |
| 书写速度 | `feed_draw` | feed_rate | |
| 点动速度 | `jog_feed` | jog_speed | 点动方向按纸面（↓ 永远朝纸张下方） |
| Z 点动步长 | `z_jog_step_mm` | Z 点动步长 | 点动面板 Z↑ / Z↓，按抬/落笔方向移动 |
| 坐标原点 | `origin = top_left / top_right / bottom_left / bottom_right` | 坐标系位置（左上/右上/左下/右下） | |
| 轴向 | `x_axis` / `y_axis` / `swap_xy` | 反转 X / 反转 Y / 对调 XY | 奎享式「左上原点」机器：`y_axis = up`，向下书写为 -Y |
| 整体偏移 / 旋转 | `offset_mm` / `rotation_deg` | 横纵坐标偏移 / 旋转 | 旋转绕纸面中心，用于纠正纸张放歪 |
| 自动设置原点 | `auto_zero_on_start` | auto_set_zero | 开始书写时 `G92 X0 Y0`，以笔尖当前位置为原点 |
| 完成后休眠 | `sleep_after_job` | autoSleep | 全部完成后发送 `$SLP` |
| 单步模式 | `stream_mode = line` | single_step_command | 每行等待 `ok` 再发下一行；默认使用更快的字符计数流控 |
| 开始 / 结束代码 | `start_gcode` / `end_gcode` | 开始前 / 结束后自定义代码 | 换行或 `;` 分隔 |
| 宏 | `macros`（最多 8 个） | 宏 1–3 | 点动面板一键执行 |
| 旧版固件 | `legacy_grbl` | 兼容旧版 GRBL | GRBL 0.9：不用 `$J=` 点动、解析逗号分隔状态；连接时也会按欢迎语自动识别 |
| 固件参数 | 机台档案 →「GRBL 固件参数」 | GRBL 参数设置 | 读取 / 修改 `$$`（写入控制板 EEPROM） |
| 英寸上报 | 自动 | — | 固件 `$13=1` 时状态坐标自动换算为毫米，暂停续写位置不偏移 |
| 字体混写 | 书写者 →「多字体混写」 | 字体 + 概率 | 每个字按权重随机选用一位书写者的 `.hwfont` 笔迹 |
| TXT 编码 | 自动 | GBK | 导入 TXT 时自动识别 UTF-8 / GBK |

## 2. 内置档案

| 档案 | 用途 |
| --- | --- |
| `kx_grbl_stepper_z` 奎享兼容 · GRBL 步进Z轴写字机 | 步进 Z 抬落笔（Z0 抬 / Z2 落，Z 速度 3000）、落笔后与抬笔前各停 0.2 s、书写 1500 mm/min、点动 2500 mm/min、左上原点向下为 -Y、开始时自动置零 |
| `kx_grbl_laser` 奎享兼容 · GRBL 激光/PWM 笔控 | 同上，笔控为 `M3 S1000` / `M5` |

以上均为通用出厂值，请按自己的机器在「机台档案」中调整（如落笔深度、速度、幅面），也可在弹窗顶部点击「奎享兼容方案」一键套用。

## 3. 首次上机

1. 安装 USB 串口驱动（多数写字机为 CH340），插上写字机。
2. 选择「奎享兼容」档案，串口保持 **自动识别**，点击连接。
3. 打开「机台档案 → GRBL 固件参数」点击读取，确认步数（`$100–$102`）与速度、加速度符合机器；
   若固件为 `$13=1`（英寸上报）无需修改，系统会自动换算。
4. **确认方向**：在点动面板按 **↓**，笔应朝纸张下方移动；若相反，把「机器 +Y 方向」改为「指向纸面下方」。
   按 **Z↓** 确认笔尖朝纸面移动，再用「抬笔 / 落笔测试」微调落笔高度。
5. 把笔尖移到纸张左上角（或开启「开始时自动置零」），执行「外框试跑」确认范围后开始书写。

## 4. 安全说明

- 急停（E-Stop）会立即软复位并向 **抬笔方向** 退刀，适用于 Z+ 为落笔的机器。
- 激光笔控请务必佩戴防护眼镜，并开启固件 `$32=1`，避免空移时拖出连线。
- 修改固件参数会写入控制板，影响所有上位机软件；修改前建议先记录原值。
